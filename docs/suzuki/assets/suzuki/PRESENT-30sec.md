## 再生成

本編 PNG の写真は、ラウンジ＋2台のスマホを1枚に入れた生成ベースが正本。日本語見出し・クレジットは PIL で重ねる。v1 は上書きしない。HTML スクショでは上書きしない。

```bash
python3 scripts/build_suzuki_slide.py
python3 scripts/build_suzuki_homescreen.py
python3 scripts/build_suzuki_pptx.py
```
